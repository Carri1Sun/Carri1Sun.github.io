之前鱼姐提过一个想做的社区，就是想看其他人跟 chatgpt 的聊天记录。

我这样拆解这个产品：跟 chatgpt 的聊天记录是一个新的思维呈现媒介形式，他能激发人呈现很多思维，其中有很多是之前呈现不出来的。

这之中重要的是这个人说了什么，问了 chatgpt 什么样的问题，以及对 chatgpt 的回复做出了什么反应，chatgpt 说了什么不是主要内容。

这样看其实重要的还是这个人本身。

我最近也有一个使用 ai 工具时的想法，我现在有收藏记录一些使用记录的愿望，我仔细想了一下发现，我想记录的是我问过这些 ai 工具什么问题以及给他们下达过什么任务，我想要的 memory 其实是记录我自己，嗯，这个就是 memory 功能设计的核心，就是"记录我自己"。这个非常重要，我想要记录的 memory 是非常明显的，非常值得做的。

然后，chatgpt 回复过的内容，这个其实对人来说是被动接受的，人要对齐进行筛选，其中也有部分有价值，但是人要进行筛选，这个东西也要做，但是不像前者那样令人兴奋立刻就可以做。
